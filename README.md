# The Scented Aura – Luxury Perfume E-Commerce Platform

## Overview

The Scented Aura is a modern luxury perfume e-commerce platform designed to deliver a premium online fragrance shopping experience. The project combines elegant UI/UX design, responsive web development, secure authentication, product management, and scalable cloud-based architecture.

The platform allows users to explore curated fragrance collections, view detailed product information, manage shopping carts, create accounts, and place orders through a seamless checkout experience.
